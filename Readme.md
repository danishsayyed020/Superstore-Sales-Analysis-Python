# Superstore Sales Analysis using Python

## 📌 Project Overview
This project analyzes Superstore sales data using Python to
identify sales trends, profitability, and business insights.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Analysis
- Overall sales and profit analysis
- Category-wise performance
- Region-wise sales analysis
- Discount vs. profit analysis
- Monthly sales trends
- Top 10 most profitable products

## 💡 Key Findings
- Technology recorded the highest sales and profit among categories.
- The West region generated the highest sales.
- November 2017 was the highest-sales month.
- Canon imageCLASS 2200 Advanced Copier generated the highest
  total profit among individual products.

## 📈 Business KPIs
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Total Customers: 793
- Profit Margin: 12.47%
